## 扫描目标

目标路径: $1

如果未指定目标，将扫描当前目录下的所有代码文件。

## 安全检查清单

### 高危漏洞
1. **SQL 注入**: 检查原始 SQL 拼接
2. **命令注入**: 检查系统命令执行
3. **XSS 漏洞**: 检查用户输入输出

### 敏感信息
4. **硬编码密钥**: 检查 API key、密码、token
5. **敏感配置**: 检查数据库连接字符串

### 权限问题
6. **权限控制**: 检查认证和授权逻辑
7. **文件操作**: 检查路径遍历风险

## 输出格式

按严重程度排序输出：

### 🔴 严重 (Critical)
必须立即修复的安全问题

### 🟡 警告 (Warning)  
建议尽快修复的潜在风险

### 🟢 建议 (Info)
可以优化的安全实践

## 报告要求

1. 标明具体文件和行号
2. 说明风险原因
3. 给出修复建议
4. 提供修复代码示例
