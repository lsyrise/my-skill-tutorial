# Code Explainer

## Instructions

1. 先读懂代码的整体功能
2. 分解成小块逐步解释
3. 使用类比和比喻帮助理解
4. 指出关键概念和技术点

## 解释结构

### 1. 一句话总结
用一句话概括这段代码做了什么

### 2. 逐步分解
按逻辑顺序解释每一部分：
- 第一步：...
- 第二步：...
- 第三步：...

### 3. 关键概念
列出代码中用到的重要概念：
- **概念A**: 简单解释
- **概念B**: 简单解释

### 4. 实际应用
说明这段代码在实际中用于什么场景

## 解释风格

1. **避免术语堆砌**: 尽量用通俗的话
2. **善用比喻**: 把复杂概念比作日常事物
3. **举例说明**: 用具体例子帮助理解
4. **循序渐进**: 从简单到复杂

## 示例解释

假设代码是一个排序算法：

> 想象你手里有一副扑克牌要排序。你从左到右看每张牌，每次找到一张更小的就和前面交换位置。
> 就像排队时，矮个子不断和高个子交换位置，最后大家按身高排好队。
