# Bug Finder

## Instructions

1. 仔细阅读代码，理解其意图
2. 按照检查清单逐项排查
3. 按严重程度对问题排序
4. 提供具体的修复建议

## 检查清单

### 内存问题
- [ ] 空指针/未定义引用
- [ ] 内存泄漏
- [ ] 数组越界
- [ ] 野指针

### 逻辑问题
- [ ] 边界条件错误
- [ ] Off-by-one 错误
- [ ] 条件判断错误
- [ ] 循环终止条件

### 类型问题
- [ ] 类型转换错误
- [ ] 整数溢出
- [ ] 精度丢失

### 并发问题
- [ ] 竞态条件
- [ ] 死锁
- [ ] 数据竞争

### 资源问题
- [ ] 资源未释放
- [ ] 文件句柄泄漏
- [ ] 连接未关闭

## 输出格式

### 🔴 严重 (Critical)
**问题**: [描述]
**位置**: [文件:行号]
**原因**: [分析]
**修复**: 
```
[修复代码]
```

### 🟡 警告 (Warning)
**问题**: [描述]
**建议**: [建议]

### 🟢 建议 (Info)
**改进点**: [描述]
**建议**: [建议]
