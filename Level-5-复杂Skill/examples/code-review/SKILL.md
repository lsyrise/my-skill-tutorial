# Code Review Skill

## Overview

这是一个全面的代码审查 Skill，提供专业级的代码审查能力。

## 适用场景

- Pull Request 审查
- 代码质量检查
- 安全审计
- 性能分析
- 代码风格检查

## Workflow

1. **理解上下文**: 首先理解代码的功能和业务背景
2. **快速扫描**: 浏览代码结构，识别关键模块
3. **详细审查**: 按照各维度检查清单逐项审查
4. **问题分类**: 按严重程度对发现的问题分类
5. **输出报告**: 提供结构化的审查报告

## 审查维度

### 🔒 安全性
检查安全漏洞和风险，详见 [SECURITY.md](SECURITY.md)

### ⚡ 性能
检查性能问题和优化机会，详见 [PERFORMANCE.md](PERFORMANCE.md)

### 📝 代码风格
检查代码规范和可读性，详见 [STYLE.md](STYLE.md)

### ✅ 综合检查
完整的检查清单，详见 [CHECKLIST.md](CHECKLIST.md)

## 输出格式

### 审查摘要

```
总体评价: [优秀/良好/需要改进/需要重写]
发现问题: X 个严重 / X 个警告 / X 个建议
审查范围: [文件列表]
```

### 问题详情

对每个问题提供：
- 严重程度 (🔴/🟡/🟢)
- 文件和行号
- 问题描述
- 修复建议
- 修复代码示例

### 改进建议

额外的优化建议和最佳实践推荐。

## 使用提示

- 提供完整的代码上下文效果更好
- 说明业务场景有助于更准确的审查
- 可以指定重点关注的审查维度
