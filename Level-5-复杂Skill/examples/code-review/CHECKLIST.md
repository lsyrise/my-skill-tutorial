# 综合审查检查清单

快速审查时使用此清单。

## 🔴 必须检查 (Critical)

### 安全
- [ ] 无 SQL 注入
- [ ] 无命令注入
- [ ] 无硬编码密钥
- [ ] 权限检查到位

### 正确性
- [ ] 业务逻辑正确
- [ ] 边界条件处理
- [ ] 错误处理完整
- [ ] 无明显 bug

## 🟡 应该检查 (Important)

### 性能
- [ ] 无 N+1 查询
- [ ] 算法复杂度合理
- [ ] 无内存泄漏
- [ ] 适当使用缓存

### 可维护性
- [ ] 代码结构清晰
- [ ] 命名有意义
- [ ] 无重复代码
- [ ] 函数职责单一

### 可读性
- [ ] 必要的注释
- [ ] 代码格式统一
- [ ] 嵌套层数合理

## 🟢 建议检查 (Nice to Have)

### 测试
- [ ] 有单元测试
- [ ] 测试覆盖关键路径
- [ ] 边界情况有测试

### 文档
- [ ] 公共 API 有文档
- [ ] README 更新
- [ ] 变更有说明

### 最佳实践
- [ ] 使用项目约定
- [ ] 遵循设计模式
- [ ] 符合 SOLID 原则
